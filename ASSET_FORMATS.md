# Asset Formats

Confidence levels: **Confirmed** means verified against the reference client by a passing test. **High** means consistent community documentation that has not yet been exercised by a test. **Unknown** is stated explicitly.

All integers are little-endian.

## GRF archive (Confirmed for 0x300, High for 0x200)

Implementation: `06_Godot_Project/scripts/resources/grf/grf_archive.gd`

### Header (46 bytes)

| Offset | 0x200 | 0x300 |
|---|---|---|
| 0 | char[16] signature (`Master of Magic`) | char[16] signature (kRO 2025: `Event Horizon\0c\0`) |
| 16 | byte[14] key (unused when not encrypted) | same |
| 30 | u32 table offset | **u64** table offset |
| 34 | u32 seed | (upper half of the u64 offset) |
| 38 | u32 count, where files = count − seed − 7 | u32 file count (exact) |
| 42 | u32 version | u32 version |

### File table at `table_offset + 46`

- 0x300 only: a leading u32. It is 0 in the reference client and its purpose is **unknown**.
- u32 compressed size, u32 uncompressed size, then a zlib stream.

### Entry

`name\0` (CP949 bytes), u32 compressed size, u32 aligned size, u32 real size, u8 flags, then the offset: u32 for 0x200, **u64** for 0x300. The offset is relative to byte 46.

Flags: `0x01` = file (0 = directory); `0x02` = mixed DES encryption; `0x04` = DES on the first 0x14 bytes only. **DES is not implemented yet.** The reference archive has no encrypted entries.

File data is a zlib stream of `compressed size` bytes.

**Evidence:** the header bytes of `data.grf`, a full table parse whose entry count matches the header (261,389), and decompressed `prontera.gat` beginning with `GRAT`.

### Names

Names are CP949 (Korean). The index stores them as lossless Latin-1 strings and lower-cases them for lookup. Folding produced 0 collisions across the reference archive (a test asserts this). `Cp949` (`scripts/resources/text/cp949.gd`) converts between the two using a table generated by `tools/gen_cp949_table.py`.

## SPR sprite sheet (Confirmed for 0x201)

Implementation: `scripts/resources/formats/spr_file.gd`

- `"SP"`, u8 minor, u8 major, u16 indexed frame count, plus u16 RGBA frame count if the version is ≥ 0x200.
- **Indexed frames:** u16 width, u16 height. For ≥ 0x201 this is followed by a u16 encoded size and RLE data: `0x00 n` means n transparent pixels (n = 0 is treated as 1), and any other byte is a literal. Older versions store w×h raw bytes.
- **RGBA frames:** u16 width, u16 height, then w×h×4 bytes in byte order **A, B, G, R**. Rows are stored **bottom-up**.
- **Palette** (≥ 0x101): the final 1,024 bytes, 256 × (R, G, B, unused). Index 0 is transparent.
- **Observed versions** (1/97 sample of the reference GRF): 0x201 only.

## ACT animation (Confirmed for 0x201, 0x203, 0x204, 0x205)

Implementation: `scripts/resources/formats/act_file.gd`

- Header: `"AC"`, u16 version, u16 action count, 10 reserved bytes.
- **Action:** u32 frame count, then that many frames.
- **Frame:** 32 bytes (two unused rectangles), u32 layer count, then the layers.
- **Layer:** i32 x, i32 y, i32 sprite index (−1 = none), i32 mirror flag. For ≥ 0x200 it continues: u8 R, G, B, A tint; scale (f32 x and f32 y for ≥ 0x204, a single f32 otherwise); i32 rotation in degrees; i32 image type (0 = indexed, 1 = RGBA). For ≥ 0x205 it adds i32 width and i32 height.
- **After the layers:** i32 sound event index for ≥ 0x200 (−1 = none). For ≥ 0x203: u32 anchor count, then per anchor 4 unknown bytes, i32 x, i32 y and 4 unknown bytes. Anchors attach heads and headgear to bodies.
- **Trailer:** u32 event count followed by 40-byte names for ≥ 0x201. For ≥ 0x202, an f32 per action giving the frame interval in **25 ms units**.
- Character and monster actions come in groups of 8 directions: `action = group * 8 + direction`. Poring has 72 actions (9 groups) and the Novice body has 104 (13 groups).
